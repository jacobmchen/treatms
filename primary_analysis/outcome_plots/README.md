## Some documentation for files in this folder.

- `plot_outcome_data.R` creates "spaghetti plots" for the outcome data EDSS, PDDS, 9hpt, and t25fw. Basically, these are just plots that show the trajectory of the outcome over time. There are 10 patients per plot. The output of these plots are in the folder `plots` and `plots_no_imputed_values`.
- `plot_changes.R` creates histograms and csv files that summarize the changes in between observed EDSS, PDDS, 9HPT, and t25fw.
